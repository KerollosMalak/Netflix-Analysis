# 📺 Netflix Data Analysis Project

This project explores the Netflix TV Shows and Movies dataset using Python. It demonstrates real-world data cleaning, exploration, and visualization techniques suitable for entry-level data analyst roles.

## 📌 Project Objective

The goal is to analyze Netflix content to uncover trends related to release years, content types, countries, and genres. The goal is to apply foundational data analysis tools to generate actionable insights.

---

## 🛠️ Tools & Libraries Used

- Python 
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🔍 Key Analyses Performed

- Handled missing values and converted date fields
- Identified trends in content release over time
- Analyzed distribution of content types (Movies vs TV Shows)
- Explored the most frequent genres and top producing countries
- Visualized results using bar charts, pie charts, and time series plots
